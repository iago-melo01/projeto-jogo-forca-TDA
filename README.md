📌 Sobre o Projeto

Este repositório contém a implementação de um Jogo da Forca em linguagem C, desenvolvido como atividade prática da disciplina Técnicas e Desenvolvimento de Algoritmos.

O objetivo do projeto é aplicar conceitos fundamentais de programação estruturada, como:

entrada e saída de dados;

estruturas condicionais;

laços de repetição;

funções;

vetores e strings;

modularização.

🎮 Como o jogo funciona

O programa escolhe ou recebe uma palavra secreta.

O jogador tenta adivinhar a palavra letra por letra.

A cada erro, o número de tentativas restantes diminui.

O jogo termina quando:

o jogador acerta todas as letras (vitória), ou

o número de erros chega ao limite (derrota).

Ao final, o programa exibe o resultado e oferece a opção de jogar novamente.
